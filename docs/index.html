Designed for one job

A gateway, not a port forwarder.

Each side gets its own reliable NetQuake channel. The proxy translates gameplay messages deliberately, enforces original client limits, and keeps unsupported extensions out of the session.

01

Translate precisely

Protocol 666 server info, entities, baselines, client data, and sounds are reduced to protocol 15 forms.

02

Respect the wire

Reliable messages are reassembled, acknowledged, and refragmented for the legacy 1024-byte datagram limit.

03

Stay intentionally small

IPv4 UDP, no runtime dependencies, bounded sessions, strict packet validation, and a hardened systemd unit.

Quick start

Three steps. One legacy entrance.

Keep QSS-M private on UDP 26000 and expose the proxy on UDP 26001. The commands below are a complete working baseline.

Build and verify

Use a C11 compiler. Windows builds run inside an MSYS2 UCRT64 shell.

git clone https://github.com/timbergeron/nq666-proxy.git
cd nq666-proxy
make
make check
# In an MSYS2 UCRT64 shell
pacman -S --needed make mingw-w64-ucrt-x86_64-gcc
git clone https://github.com/timbergeron/nq666-proxy.git
cd nq666-proxy
make
make check

Start the gateway

Replace the example public IP. Omit --advertise only when every player connects directly.

./nq666-proxy \
  --server 127.0.0.1:26000 \
  --listen 0.0.0.0:26001 \
  --advertise 203.0.113.10:26001 \
  --verbose

Connect the client

Open UDP 26001 in the firewall. Original clients connect to the proxy, never the private QSS-M endpoint.

connect 203.0.113.10:26001

Deployment

Expose the edge. Protect the server.

The cleanest deployment keeps QSS-M and the proxy on the same host. Only the legacy-facing UDP listener needs to be public.

nq666-proxy Translation and session boundary

Recommended boundary

Keep the upstream on loopback unless modern clients also need direct access. If both generations play, expose two distinct UDP ports.

  • Allow the proxy port as UDP, not TCP.
  • Use --advertise for server-browser connects.
  • Start with verbose logging before daemonizing.
  • Apply normal VPS UDP filtering and rate limits.

Install with systemd

Run sudo make install, copy the provided default file to /etc/default/nq666-proxy, edit NQ666_ARGS, then enable the service.

Know the trust boundary

RCON is deliberately not relayed. QSS-M sees the proxy host and a unique source port—not the original player IP. This is compatibility infrastructure, not a DDoS filter.

sudo make install
sudo install -m 0644 \
  /usr/local/share/doc/nq666-proxy/nq666-proxy.default \
  /etc/default/nq666-proxy
sudo editor /etc/default/nq666-proxy
sudo systemctl daemon-reload
sudo systemctl enable --now nq666-proxy
sudo systemctl status nq666-proxy

Compatibility envelope

Faithful to the original limits.

Translation cannot enlarge a 1996 client’s internal tables. Resources beyond these limits are safely hidden, omitted, or rendered without a model.

Resource Legacy-facing limit Behavior above the limit
Scoreboard slots 16 Additional scoreboard updates are hidden.
Models 255 precaches Higher model indices render as no model.
Sounds 255 precaches Higher sound events are omitted.
Dynamic entities 600 WQ / 2048 PQ Higher entity updates are omitted.
Static entities 128 Additional static entities are omitted.
Light styles 64 Higher style updates are omitted.

In scope

  • Base protocol 666 to protocol 15 translation
  • WinQuake 8-bit and ProQuake 16-bit movement angles
  • Reliable fragment reassembly and refragmentation
  • Server-browser queries with address rewriting
  • Standard Quake and similarly sized multiplayer maps

Deliberately out of scope

  • FTE replacement deltas and CSQC
  • Downloads and voice transport
  • RMQ protocol 999 and DarkPlaces protocols
  • IPv6 and TCP forwarding
  • RCON relay or source-IP restoration

CLI reference

Small surface. Clear behavior.

Only --server is required. Defaults favor a private upstream and a separate public legacy port.

Option Purpose
-s, --server ADDR QSS-M protocol 666 endpoint. Port defaults to 26000.
-l, --listen ADDR Legacy-facing listener. Defaults to 0.0.0.0:26001.
-a, --advertise ADDR Public address written into server-browser replies. The listener port is appended when omitted.
-m, --max-sessions N Total session slots. Defaults to 64 and is capped at 256.
-v, --verbose Log connections, malformed packets, and translation errors.
--version / --help Print the proxy version or complete command-line help.
